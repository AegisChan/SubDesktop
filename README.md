## 📖 项目简介

`SubDesktop` 是一款专为 Windows 10 / 11 深度定制的轻量级、便携式虚拟子桌面增强工具。它允许用户将本地任意磁盘的物理文件夹映射为一个具备完整桌面交互能力的独立“子桌面视窗”。

无论是整理杂乱的临时工作区、隔离多项目开发文件，还是针对不同使用场景（办公、学习、素材归档、多屏投屏）打造专属桌面环境，`SubDesktop` 都能在提供沉浸式桌面体验的同时，确保底层物理文件与系统配置的绝对纯净与安全。

## 🌟 核心特性

### 1. 🛡️ 物理数据绝对安全（最高安全红线）
- **解绑与真实数据严格隔离**：用户在任何场景下执行“删除子桌面”、“清理桌面快捷方式”或“重置配置”，**实质仅为解除映射关系**（仅清理 `./profiles/<id>/` 元数据与对应桌面 `.lnk`），**绝对禁止以任何形式删除或修改映射物理路径下的真实文件**！
- **原生回收站安全删除**：子桌面视窗内触发的所有文件/文件夹删除操作强制调用 Windows 原生回收站接口（`send2trash`），严禁任何不可逆物理硬删除（`os.remove` / `shutil.rmtree`）。
- **零外部环境污染**：程序运行产生的全部配置文件、图标缓存、固化壁纸等完全收敛在项目目录下的 `./profiles/` 内，不在系统其它磁盘产生任何垃圾文件。

### 2. 🖥️ 独立视窗与多子桌面管理
- **预设与自定义分辨率**：内置 `640×480`, `800×480`, `960×540`, `800×600`, `1024×768`, `1280×720`, `1366×768`, `1600×900`, `1920×1080` 等经典预设分辨率，并支持像素级任意自定义宽高。
- **壁纸固化隔离**：导入壁纸时自动复制并隔离固化保存，外部源壁纸移动或删除不影响子桌面的渲染。
- **双层紧凑控制台**：管理中心卡片采用双层流式布局，自适应截断超长路径，所有快捷操作按钮一目了然、无需横向滚动。
- **规范命名与自动序号**：Profile 目录采用整洁的 `profile_{safe_name}` 规则，同名自动追加 `_1`、`_2` 自增序号，完全兼容老版本。

### 3. 📐 自适应网格与防碰撞占位机制
- **标准矩阵网格对齐**：基于 76×90px 标准卡片单元构建网格坐标系统，释放时自动吸附对齐，确保如同 Windows 原生桌面般横平竖直。
- **网格防碰撞占位（Occupancy Check）**：若释放目标网格已被其他图标占用，自动根据曼哈顿距离计算就近顺延至最近的空闲网格，绝不发生图标重叠与内容遮挡。
- **记忆与兜底持久化**：以纯文件名（`os.path.basename`）为唯一键值实时记录坐标，关闭视窗与退出时执行全量坐标兜底保存，彻底解决重新打开堆叠回左上角的问题。

### 4. 📦 安全移动拖拽与流校验
- **零冗余、防意外丢失**：从外部 Windows 资源管理器拖拽文件入窗时，系统先将完整文件流写入映射目录，校验源与目标文件大小完全一致后，再通过回收站清理源文件，既不产生冗余副本，又确保数据 100% 完整。

### 5. 🎨 细腻视觉质感与 Windows 原生系统集成
- **高质感半透明选框**：参考 Windows 10/11 原生桌面视觉规范，未选中时背景完全通透，选中时呈现通透微蓝高亮（`rgba(0, 120, 215, 0.2)` 填充、0.5 描边、4px 圆角）。
- **抗锯齿与多分辨率图标**：多分辨率 `QFileIconProvider` 优先提取，配合 `Qt.SmoothTransformation` 平滑重采样，消除白底小图标边缘毛刺锯齿。
- **重命名失焦自动确认**：就地重命名支持回车与鼠标点击空白（失焦 blur）自动提交保存，空值自动回退，按 <kbd>Esc</kbd> 撤销，不再残留白色输入框。
- **原生系统图标快捷方式**：生成纯净名称快捷方式（如 `WorkDesktop.lnk`），自动挂载 Windows 原生虚拟桌面图标库（`imageres.dll, 110`）。

## 📂 项目结构

```text
SubDesktop/
├── AGENTS.md                   # 工程规范与最高安全红线守则
├── requirements.txt            # 项目依赖清单
├── build.bat                   # 一键 PyInstaller 便携编译打包脚本
├── main.py                     # 启动分流引擎 (--manager / --profile <id>)
├── core/                       # 核心业务逻辑层 (纯本地化，无外部数据库依赖)
│   ├── __init__.py             # 核心组件导出接口
│   ├── config.py               # 常量定义、网格步长、预设分辨率与配置模型
│   ├── profile_storage.py      # Profile 持久化引擎（壁纸固化、解绑删除安全隔离、规范命名）
│   ├── shortcut_helper.py      # Windows 桌面快捷方式 (.lnk) 生成、清理与原生图标挂载
│   ├── shell_icon.py           # Windows 原生高精度图标提取工具（带 Smooth 缩放抗锯齿）
│   └── file_ops.py             # 文件安全门禁（安全移动流校验、send2trash 回收站删除）
├── ui/                         # 界面表现层 (PyQt5)
│   ├── styles.py               # 现代化精美扁平 QSS 样式定义
│   ├── manager_window.py       # 主控制台管理窗口 (紧凑双层卡片列表、路径截断、快速操作)
│   ├── profile_dialog.py       # 创建/编辑对话框 (路径浏览、分辨率下拉、壁纸导入)
│   ├── desktop_window.py       # 独立子桌面视窗 (高 DPI 适配、尺寸记忆、目录动态监听)
│   ├── desktop_canvas.py       # 桌面画布 (壁纸绘制、防碰撞网格对齐、框选多选、安全拖入)
│   └── desktop_icon.py         # 桌面图标控件 (细腻半透明选中态、文字阴影、失焦重命名)
├── profiles/                   # 隔离配置存储根目录 (.gitkeep 保留目录结构)
└── tests/
    └── test_sandbox_safety.py  # 核心安全红线与功能自动化测试套件 (严格在 ./test_sandbox/ 运行)
```

## ⌨️ 常用快捷键与操作

| 动作 | 触发方式 | 说明 |
| :--- | :--- | :--- |
| **打开文件 / 文件夹** | 鼠标双击 或 <kbd>Enter</kbd> | 调用系统关联程序打开或进入子文件夹 |
| **就地重命名** | 选中后按 <kbd>F2</kbd> | 支持回车确认、鼠标失焦自动保存、<kbd>Esc</kbd> 撤销 |

| **刷新桌面** | 视窗空白处右键菜单 -> 刷新 | 重新扫描映射物理目录并保留现有图标排布 |
| **快速新建** | 视窗空白处右键菜单 -> 新建 | 快速新建文件夹或文本文档 |

## 🚀 快速上手与运行

### 1. 环境准备
推荐使用 Python 3.10 及以上环境（支持 Python 3.10 ~ 3.13）：

```bash
pip install -r requirements.txt
```

### 2. 启动主管理控制台
```bash
python main.py
# 或显式指定
python main.py --manager
```

### 3. 直接启动指定子桌面视窗
可通过命令行参数或桌面生成的 `.lnk` 快捷方式直达子桌面：
```bash
python main.py --profile profile_default
```

## 🛡️ 安全自动化验证测试

本项目包含涵盖 9 项安全红线与交互特性的自动化测试套件。所有文件操作严格限定在 `./test_sandbox/` 临时沙盒中，全面验证**解除映射时的真实文件 100% 完整性**、`send2trash` 安全删除以及坐标持久化等机制：

```bash
python -m unittest discover tests -v
```

测试覆盖范围：
- `test_01`: 最高安全红线（解绑子桌面时物理真实数据零删除）
- `test_02`: 原生回收站删除有效性
- `test_03`: 新建文件/文件夹同名防覆盖自动递增
- `test_04`: 纯净快捷方式命名与路径清理逻辑
- `test_05`: 外部拖入安全移动与字节大小一致性校验
- `test_06`: 坐标持久化与关闭重开防堆叠
- `test_07`: 曼哈顿距离网格防碰撞占位就近顺延
- `test_08`: 规范并精简 Profile 目录命名与自增
- `test_09`: 重命名输入框失焦自动提交与空值安全回退

## 📦 打包构建为便携独立程序

双击运行根目录下的 `build.bat`（或调用命令行）即可一键完成 PyInstaller 便携独立目录打包：

```bat
build.bat --no-pause
```

- **便携输出目录**：`dist/SubDesktop/`
- **主启动程序**：`dist/SubDesktop/SubDesktop.exe`
- **便携包特性**：内含完整独立的 Python 运行时与 PyQt5 库，内置 `profiles/` 隔离配置目录，解压/拷贝到任意 Windows 10/11 64位电脑上即开即用，无需配置 Python 环境。
